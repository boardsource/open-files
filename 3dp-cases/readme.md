

# Boardsource 3D Printed Keyboard Case Prototypes



This repository contains prototype 3D printed cases for popular split and ergonomic keyboard layouts, designed to work with **Boardsource FR4 case kits**.

Each file contains **only one half** of the case — you will need to mirror it for the opposite side.



## Supported Layouts



* **Corne** (CRKBD)

* **Lily**

* **Reviung41**

* **Sweep**



## Design Intent



These cases are meant to complement Boardsource’s **FR4 case kits**, using the FR4 plates and hardware for mounting.

The 3D printed shell provides an alternative look and feel while keeping the same core layout and build style.



### Goals



* Test alternative shapes and profiles

* Validate fitment with FR4 kit hardware

* Provide a starting point for further community experimentation



## Status



> **Prototype quality:** These are **not production models**. Fit, finish, and tolerances may vary.

> Minor sanding or post-processing may be required for perfect assembly.



Known caveats:



* Only one side is provided; mirror it for the opposite hand

* Tolerances are intentionally loose to allow for printer variation

* Designed for **M2 hardware** included in Boardsource FR4 kits



## Printing Guidelines



Recommended settings (PLA/PLA+):



* **Layer Height:** 0.2 mm

* **Walls:** 3+

* **Infill:** 20–30%

* **Supports:** Minimal, only where needed

* **Bed Adhesion:** Skirt or brim if warping is a concern



Always check hole and post fitment before full assembly.



## Assembly



1. Print the provided side and mirror it for the other hand

2. Install FR4 plate and PCB from your Boardsource kit

3. Use FR4 kit standoffs, screws, and feet for assembly

4. Test key clearance before tightening screws fully
